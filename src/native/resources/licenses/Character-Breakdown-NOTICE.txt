Changes made by Syng on 2026-10-27:
Syng selects formation notes, component names and roles, verification flags,
stroke counts and eligible modern vectors. Notes are whitespace-trimmed, not
rewritten. Missing information is not generated. Historical images are omitted.

The generated chars/ files contain Dong Chinese notes, components, and any Dong
Chinese vectors. LGPL radical fields are kept in radicals.json. Selected Arphic
vectors are kept in arphic/, with a dated modification notice in each file. The
app joins these resources for display without changing their respective licenses.

Exact source URLs, SHA-256 hashes, the graphics revision, changes and the import
report ship in resources/character-breakdown/manifest.json. The reproducible
importer is scripts/prepare-character-breakdown.mjs in the Syng source release.
Sources and modifications: https://github.com/sotch-pr35mac/syng/tags
Use the Git tag corresponding to the installed release for the matching importer,
source pins, notices, and setup scripts. The manifest identifies the dated Dong
Chinese dump, exact Make Me a Hanzi commit, and Hanzi Writer graphics revision.
